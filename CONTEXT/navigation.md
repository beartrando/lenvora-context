# Navigation

- CONTEXT-файлы — рабочий инструмент, а не неизменяемая документация: их можно
  свободно редактировать и дополнять по мере изменения кода. Главное — чтобы
  содержание оставалось понятным и соответствовало текущему состоянию проекта.
- Задача в коде бэкенда → [services/](../services**/CONTEXTpurpose.md) → нужный сервис.
- Задача в общей библиотеке → [shared/](../shared**/CONTEXTpurpose.md).
- Задача в контрактах RPC → [proto/](../proto**/CONTEXTpurpose.md).
- Задача по сборке/деплою → `Makefile`, `.github/workflows/`, `docker-compose*.yml`.
