# Контекст Lenvora infra

Рабочий контекст AI-агента монорепозитория Lenvora infra. Зеркалит дерево проекта: корень → [services/](services/purpose.md), [shared/](shared/purpose.md), [proto/](proto/purpose.md).

Как читать:

- открывать только узлы, относящиеся к текущей задаче;
- начинать с [purpose.md](purpose.md) узла и идти вниз по [children](children.md) и [navigation](navigation.md);
- каждый узел — набор файлов: purpose, responsibility, structure, children, parent, abstraction-level, architectural-rules, dependencies, dependency-direction, entry-points, important-files, navigation, non-responsibility.

Процесс работы (git-workflow, lifecycle тикета) и долговременные технические знания живут в отдельном репозитории wiki — читать его до начала работы; данный контекст описывает только устройство проекта.
