# Dependency direction

```text
корень (конфигурация, Makefile, CI)
   ├── собирает/запускает → services/
   ├── резолвит как workspace → shared/
   └── генерирует код из → proto/

services/ → shared/   (импорт @shared/*)
services/ → proto/    (генерация кода контрактов)

shared/ → (нет зависимостей от сервисов)
proto/  → (нет зависимостей от монорепы)
```

Корень — верхний уровень координации; нижние узлы на него не ссылаются. Потребители корня — разработчик и CI.
