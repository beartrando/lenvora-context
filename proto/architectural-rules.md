# Architectural rules

- Контракт меняется здесь; серверная реализация — в [services/](../services/purpose.md), клиенты обновляются генерацией.
- После любого изменения контракта — `make proto-generate` в [корне](../purpose.md) во всех потребителях.
- Синтаксис proto3; `package` = имя сервиса; общие типы импортируются из `common/`, не дублируются.
- Сгенерированный код в proto/ не хранит — только `.proto`-исходники.
- Репозиторий отдельный (подмодуль): коммиты и push — в нём, см. `make/git.mk` (`GIT_EXTRA_REPOS`).
