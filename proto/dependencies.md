# Dependencies

- Внешние: `protoc` (генерация), типы `google/protobuf/*` (например, `timestamp.proto`).
- Инструменты генерации потребителей: `ts-proto` (плагин из зависимостей [корня](../purpose.md)), dart-бэкенд protoc для front.
- Внутренних зависимостей от сервисов или `@shared/*` нет — узел нижнего уровня.
