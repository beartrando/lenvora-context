# Non-responsibility

- Не содержит серверной логики и бизнес-правил бэкенда — только отображение и клиентские вызовы.
- Не обслуживает gRPC и не раздаёт API — публичный доступ через [gateway](../gateway/purpose.md).
- Не генерирует protobuf-контракты вручную: `make proto-generate` (корень) и CI; аудио/транскрипции в UI не обрабатываются — контракт speech-to-text в сгенерированных типах отсутствует.
- Не хранит данные на сервере: локально SharedPreferences и secure storage.
- Не владеет токен-выдачей — логика выпуска на бэкенде ([auth](../auth/purpose.md)), здесь только хранение и refresh-вызовы.
- Не собирает десктоп и web в CI: workflow собирает и публикует только Android App Bundle.
- Не тестирует поведение UI: `test/widget_test.dart` — заглушка, автотестов фич нет.
