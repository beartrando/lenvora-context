# gusteau — gRPC-сервис учёта питания: продукты, коэффициенты, дневник

Ведёт продукты профиля, нутриентные коэффициенты (белки/жиры/углеводы) и записи дневника питания; данные — в PostgreSQL через Prisma.

Единственная поверхность — внутренний gRPC на 50051 (сервис `Gusteau` + health). HTTP и WebSocket нет.
