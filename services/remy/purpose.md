# remy — AI-сервис: gRPC-обработка текста через LLM

Отвечает на gRPC `Remy.Process(text)` текстовым результатом; текущий use-case возвращает эхо входа и в модель не ходит (в коде указан путь подключения через AI-порт).

Отдельная подсистема `src/infrastructure/ai` инкапсулирует AI-клиент (OpenRouter через SDK `openai`), в wiring сервиса пока не подключена.
