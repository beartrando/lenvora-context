# Dependencies

- Внешние: `openai ^5` (SDK провайдера) — единственная runtime-зависимость модуля.
- Env: не читается — `AiConfig` передаётся в конструктор явно.
- Внутри сервиса: модуль самодостаточен — импортирует только собственные файлы;
  `@shared/*` и contracts не нужны.
- Обратная сторона: модуль никем не импортируется (wiring не выполнен).
