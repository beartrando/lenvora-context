# Architectural rules

- SDK `openai` не выходит за пределы `clients/openrouter.ts`; остальной код работает с портом `AiClient`.
- Конфиг один и читается из env на старте; ключи и адрес модели в коде не хардкодятся.
- Добавление провайдера = новый клиент + ветка в `createAiClient`, без изменения `AiService`.
- Фасад не содержит бизнес-логики, промптов и знаний о gRPC/провайдере — только делегирование (зафиксировано в комментарии `service.ts`).
- Тесты узла — юнитные с моком фабрики, внешняя сеть не используется.
