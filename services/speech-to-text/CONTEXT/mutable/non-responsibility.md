# Non-responsibility

- Хранение и выдача сохранённых транскрипций, любая БД — по решению отсутствуют.
- Доставка до клиента: WS-канал, реестр сокетов, события — это `streaming`.
- HTTP-доступа снаружи: маршруты gateway/orchestration для сервиса не заводятся.
- Выбора провайдера в бизнес-логике — только через `STT_*`-конфиг.
- Продукты, журнал еды — не относятся к этому сервису.
