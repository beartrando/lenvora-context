# Non-responsibility

- Хранение и выдача сохранённых транскрипций, любая БД — по решению отсутствуют.
- Доставка до клиента: WS-канал, реестр сокетов, события — это `streaming`.
- Авторизация: проверка JWT и принадлежности профиля — на уровне streaming
  (WS-сессия) и orchestration; сервис получает профиль в `audio_start` как
  данные и не верифицирует его.
- HTTP-доступа снаружи: маршруты gateway/orchestration для сервиса не заводятся.
- Выбора провайдера в бизнес-логике — только через `SPEECH_TO_TEXT_*`-конфиг.
- gusteau-наследие (продукты, журнал еды) — чужой код; удалено из этого сервиса.
