# Architectural rules

- Новый код ошибки = правка `proto/common/error.proto` → `pnpm proto:generate` → класс в `src/errors/` → ре-экспорт в `src/index.ts`. Обход генерации запрещён.
- `src/contracts/proto/**` — generated code, руками не редактируется (шапка «Code generated by protoc-gen-ts_proto»).
- Класс наследует `DomainError` и фиксирует `readonly code` из `errorProto.ErrorCode`; произвольные `Error` с кодом в сервисах не создают — используют классы пакета.
- Публичный контракт — только именованные классы из `src/index.ts`; `ErrorCode`, `ErrorObject`, хелперы `errorCodeFromJSON/ToJSON` наружу не экспортируются.
- Классы не содержат логирования и трансляции в ответ — это отдельный слой потребителя.
