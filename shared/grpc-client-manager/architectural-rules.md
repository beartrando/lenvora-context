# Architectural rules

- `call()` принимает только колбэковый unary-вызов `(client, cb)`; стримы менеджер не поддерживает — потоковые клиенты создаются в сервисах напрямую (см. комментарий в `services/streaming/src/infrastructure/grpc/clients/speech-to-text.client.ts`).
- Фабрика обязана создавать полностью настроенного клиента (адрес + credentials): менеджер ничего не дополняет и не читает конфигурацию.
- Один менеджер — один клиент на инстанс; параллельные `call` разделяют его, кэша/пула нет.
- Ретраи ограничены двумя попытками и фиксированным списком кодов — расширение затрагивает все сервисы.
- Не-восстановимая ошибка не повторяется; повторная попытка — только после успешного `reconnect()`.
