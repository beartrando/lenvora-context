# Non-responsibility

- Не управляет инфраструктурой Kafka (брокер, схема-реестр, docker-compose) — только клиентские операции.
- Не знает топики, группы и обработчики сервисов — конфигурация и `handler` приходят снаружи.
- Не сериализует по схемам (Avro/protobuf/JSON Schema) — только `JSON.stringify`/`JSON.parse`.
- Не обрабатывает бизнес-логику сообщений — хандлеры в `services/*/src/infrastructure/message/consumers/`.
- Не обеспечивает повторную доставку, идемпотентность и порядок сообщений; не балансирует партиции (используется DefaultPartitioner).
- Не читает конфигурацию из окружения и не управляет жизненным циклом приложения (остановка producer'а — в сервисе).
