# Architectural rules

- Импорт только через корень пакета: `import logger from "@shared/logger"` (или `import { logger } from ...`) — субпутей нет.
- Формат вывода держать стабильным: на нём строятся чтение логов в docker-compose и диагностика.
- Методы не возвращают значений, не бросают исключений и не принимают контекст/уровень — API расширять нельзя без пересмотра формата.
- В пакете не появляются зависимости и I/O: только `typescript` в devDependencies.
- В тестах потребителей логгер мокают целиком (`jest.mock('@shared/logger')`), а не подменяют транспорт.
