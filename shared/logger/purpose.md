# logger — консольный логгер с меткой времени и локацией вызова

`@shared/logger` — минимальный синглтон-логгер: печатает ISO-время, аргументы и место вызова (файл:строка из стека) через `console.log`.

Экспортирует default и именованный `logger` с методами `log`, `info`, `warn`, `error` — все пишут в stdout в одном формате.

Используется всеми 8 Node-сервисами и остальными библиотеками `shared/` (kafka-manager, grpc-client-manager, pg-boss-manager).

Единственный исходник — `src/index.ts` (~60 строк); runtime-зависимостей нет.
