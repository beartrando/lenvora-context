# Non-responsibility

- Не владеет PostgreSQL: создание/миграция схемы `pgboss`, пул соединений и настройки СУБГ — на стороне pg-boss и инфраструктуры (`services/postgres`, pgbouncer, docker-compose).
- Не содержит бизнес-обработчиков задач — воркеры регистрируют сервисы (`infrastructure/job`, consumers).
- Не является Kafka-консьюмером: мост односторонний (pg-boss → Kafka), обратной доставки из Kafka в очередь нет.
- Не планирует cron/таймеры вне очереди, не задаёт приоритеты, retry-политику и расписание задач (это API pg-boss).
- Не читает конфигурацию топиков и Kafka — `KafkaConfig` и список топиков приходят от сервиса.
- Не логирует бизнес-события — только инфраструктурные записи через [logger](../logger/purpose.md).
